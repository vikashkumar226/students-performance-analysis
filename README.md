# 📊 Students Performance in Exams - Machine Learning Prediction

An end-to-end Machine Learning project to predict student examination scores based on demographic and academic factors using **Linear Regression**.

---

## 📌 Project Overview
The objective is to understand how various factors such as gender, ethnicity, parental education level, lunch type, and test preparation course impact students' academic performance, and accurately predict their math scores.

- **Dataset:** Student Performance in Exams (Kaggle)
- **Algorithm:** Linear Regression (Scikit-Learn)
- **Key Libraries:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

---

## 📈 Model Performance
- **R² Score:** `0.8804` (88.04% variance explained)
- **RMSE (Average Error):** `5.39 marks`
